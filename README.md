# Video-to-Data API

Turns a video's caption track (WebVTT or SRT) into structured JSON: chapters, an extractive summary, action items with owners, entities (money, percentages, dates, URLs, emails, names) and talk time per speaker. Ships with a typed TypeScript SDK and a browser playground.

**Live:** https://video-to-data-api.braylo777.workers.dev · `POST /v1/extract` · `GET /v1/health`

> **Scope, stated plainly:** this reads captions/transcripts, not pixels or audio. Any video with a caption track (YouTube, Zoom, Loom exports) works; speech-to-text is out of scope. The demo meeting and all eval transcripts are **synthetic**.

## API
```bash
curl -s https://video-to-data-api.braylo777.workers.dev/v1/extract \
  -H 'content-type: application/json' \
  -d '{"captions":"WEBVTT\n\n00:00:00.000 --> 00:00:05.000\n<v Ana>Raj will send the contract by October 30."}'
```
Errors: `400 invalid_json | captions_required`, `405`, `413 too_large` (2 MB), `422 parse_error | no_cues`.

## SDK
```ts
import { VideoToData } from "./sdk";
const x = await new VideoToData().extract(vtt);   // typed Extraction; retries 5xx with backoff; throws VideoToDataError
x.chapters.forEach(c => console.log(c.start, c.title));
```

## How it works
- **Parser** (`src/parse.ts`): WebVTT and SRT, voice tags and `Name:` speakers, sorted cues.
- **Chapters** (`src/extract.ts`): TextTiling-style segmentation: cosine similarity between adjacent cue windows, smoothed, boundaries at depth-score valleys above mean + 1σ, with a minimum gap. Titles from per-chapter TF-IDF.
- **Entities/action items:** regex rules; owners from "X will/should/needs to" patterns.

## Evaluation (synthetic, honest)
`npm run eval` scores chapter boundaries against labeled transcripts generated by `fixtures/gen.ts` (topic chapters of varying length, 20 s tolerance). Parameters were tuned on the **dev** set (seed 42) only; the **holdout** set (seed 7, 8 transcripts) was not used for tuning.

| Set | Segmenter F1 | Naive "split every 90 s" F1 |
| --- | --- | --- |
| dev (3) | 0.842 | 0.300 |
| holdout (8) | **0.682** | 0.243 |

A test fails CI if holdout F1 drops below 0.6 or stops beating the naive baseline. Synthetic topics are lexically clean, so expect lower scores on real meetings.
