Video-to-Data API

Turns a video's caption track (WebVTT or SRT) into structured JSON: chapters, summary, action items, entities and talk time. It reads captions, not pixels. The demo meeting is fictional. Source, SDK, eval

API: POST /v1/extract {"captions": "<WebVTT or SRT>"} · GET /v1/health
SDK: new VideoToData().extract(vtt)
